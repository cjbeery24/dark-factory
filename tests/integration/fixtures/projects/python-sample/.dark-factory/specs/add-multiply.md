# add-multiply

## Functional Requirements
- FR-1: multiply(a, b) returns the product of two numbers
- FR-2: multiply handles float arguments
- FR-3: multiply(0, x) returns 0 for any x

## Acceptance Criteria
- AC-1: multiply(3, 4) == 12
- AC-2: multiply(2.5, 4.0) == 10.0
- AC-3: multiply(0, 99) == 0
