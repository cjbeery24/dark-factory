# Dark Factory Example: REST API

A complete, runnable example demonstrating the Dark Factory pipeline from init to shipped code.

## Prerequisites

- Docker Desktop running (`docker info` should work)
- Claude Code installed (`claude --version`)
- Python 3.11+
- Git
- **Dark Factory CLI installed:** `pip install -e /path/to/dark-factory` (see [QUICKSTART.md](../../docs/QUICKSTART.md))
- **Auth credentials set:** `CLAUDE_CODE_OAUTH_TOKEN` or `ANTHROPIC_API_KEY` in your environment (see [INTEGRATION.md](../../docs/INTEGRATION.md#authentication))

## Walkthrough

### 1. Initialize the project

```bash
cd examples/rest-api
dark-factory init
```

This detects the Python/FastAPI project, creates `.dark-factory/config.toml`, and sets up the directory structure. You can also run `dark-factory setup validate` to verify everything is ready.

### 2. Review the generated config

```bash
cat .dark-factory/config.toml
```

The init command auto-detected:
- Language: Python
- Source dir: `src/app`
- Test dir: `tests`
- Lint: `ruff check .`
- Test: `pytest`

### 3. Build Docker images

```bash
bash ../../docker/build-images.sh python
```

This builds the sandboxed containers that enforce information barriers between agents.

### 4. Review the plan

The plan at `.dark-factory/plans/rest-api-plan.md` decomposes the project into 3 specs:
1. Health endpoint + user CRUD
2. Input validation
3. JWT authentication

### 5. Run the pipeline on the first spec

```bash
dark-factory run 01-health-endpoint
```

The pipeline will:
1. Validate the spec (completeness check)
2. Generate blind test scenarios (without seeing the code)
3. Implement the code (without seeing the scenarios)
4. Run quality gates (build, lint, type check, blind scenarios)
5. Review the implementation
6. Ship or iterate

### 6. Check the results

```bash
dark-factory dashboard
dark-factory metrics
```

## Troubleshooting

If something goes wrong, see [TROUBLESHOOTING.md](../../docs/TROUBLESHOOTING.md) for exact fix commands.

Common first-run issues:
- **`Docker daemon not running`** — Start Docker: `open -a Docker` (macOS) or `sudo systemctl start docker` (Linux)
- **Auth errors** — Ensure `CLAUDE_CODE_OAUTH_TOKEN` or `ANTHROPIC_API_KEY` is exported in your shell
- **Docker image not found** — Run `bash ../../docker/build-images.sh python`

## Project Structure

```
rest-api/
├── pyproject.toml              # Project config
├── Dockerfile                  # Container for ephemeral deploy
├── docker-compose.test.yml     # Ephemeral test environment
├── src/app/
│   ├── __init__.py
│   └── main.py                 # FastAPI application (3 endpoints)
├── tests/
│   └── test_health.py          # Starter test
└── .dark-factory/
    ├── config.toml             # Generated by `dark-factory init`
    ├── plans/
    │   └── rest-api-plan.md    # 3-spec project plan
    └── specs/
        └── 01-health-endpoint.md  # First spec (ready to run)
```
